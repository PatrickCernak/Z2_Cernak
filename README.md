Obsah:  
Stránka slúži na prezeranie obedových menu reštaurácií v okolí FEI STU. Nachádzajú sa tu jedálne lístky reštaurácií Eat & Meet, DRAG a FIIT Food. Používateľ si môže vybrať deň v týždni, zobraziť celý týždeň alebo filtrovať jednotlivé reštaurácie. Menu sa načítava z lokálnych HTML súborov, spracúva pomocou JavaScriptu a ukladá do localStorage.

Stránku som vytvoril pomocou HTML, CSS a JavaScriptu. Použil som aj knižnice jQuery a Bootstrap.
